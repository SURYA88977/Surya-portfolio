Everything you need to know about how JavaScript talks to HTML — from selecting elements to handling events, traversing the tree, and building real interactive projects.

JavaScript is one of the most important technologies used to make websites interactive. HTML provides the structure of a webpage, CSS controls its appearance, and JavaScript adds behavior and functionality.

But how does JavaScript actually change the content, style, buttons, forms, images, and other elements on a webpage? The answer is the DOM — Document Object Model.

The DOM is the bridge between JavaScript and the HTML/CSS that make up a page. Using it, JavaScript can find elements, change their content, modify their styles, create new elements, remove existing ones, and respond to user actions such as clicks, typing, mouse movement, and keyboard input.

This guide walks through the DOM from the fundamentals to more advanced, practical patterns.

01What is the DOM?

DOM stands for Document Object Model.

When a browser loads an HTML document, it converts the HTML code into a structured object called the DOM tree. Take this simple page: 

html<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>

    <h1>Hello World</h1>
    <p>Welcome to my website.</p>

    <button>Click Me</button>

</body>
</html>

The browser turns this into a tree-like structure of nodes:

Document │ └── html │ ├── head │ └── title │ └── body │ ├── h1 │ ├── p │ └── button

Every HTML element becomes an object/node that JavaScript can reach and manipulate.

02Why is the DOM important?

Without the DOM, JavaScript would have no reliable way to interact with the elements on a page. With it, you can:

Content & structure

Change HTML content, create new elements, delete elements, and change attributes.

Style & appearance

Change CSS styles and add or remove classes to switch visual states.

Interaction

Handle clicks, keyboard input, mouse events, and validate forms.

Applications

Build interactive interfaces and full dynamic web applications.

A simple example — changing a heading's text:

jsdocument.querySelector("h1").textContent = "Welcome Surya!";

03The document object

The main entry point for DOM manipulation is the document object — it represents the entire HTML document currently loaded in the browser.

jsconsole.log(document);

You can read page details from it:

jsconsole.log(document.title);

...and even change them, which updates the browser tab title immediately:

jsdocument.title = "My New Website";

04DOM nodes

Everything in the DOM is represented as a node. The common types are:

Document node

Represents the entire HTML document: document

Element node

Represents an HTML element, e.g. <h1>Hello</h1>

Text node

The text inside an element — in <p>Hello World</p>, "Hello World" is a text node.

Attribute

Info attached to an element, like src and alt in <img src="photo.jpg" alt="Profile">

05Selecting HTML elements

Before modifying an element, JavaScript usually needs to find it first. There are several selection methods, each with its own use case.

getElementById()

Selects a single element by its id. Note: you don't include # here.

html<h1 id="title">Hello World</h1>
jsconst title = document.getElementById("title");
console.log(title);

getElementsByClassName()

Selects elements by class name and returns an HTMLCollection.

html<p class="text">Hello</p>
<p class="text">Welcome</p>
jsconst elements = document.getElementsByClassName("text");
console.log(elements[0]); // access by index

getElementsByTagName()

Selects elements based on their HTML tag.

jsconst paragraphs = document.getElementsByTagName("p");
console.log(paragraphs);

querySelector()

One of the most commonly used DOM methods — it accepts standard CSS selectors and returns only the first matching element.

jsconst title = document.querySelector("#title");
const box = document.querySelector(".box");
const paragraph = document.querySelector("p");
const button = document.querySelector(".container button");

querySelectorAll()

Returns all matching elements, which you can loop through directly with forEach.

jsconst paragraphs = document.querySelectorAll("p");

paragraphs.forEach(function(paragraph) {
    console.log(paragraph.textContent);
});

06Changing HTML content

Once an element is selected, JavaScript can change what's inside it.

html<h1 id="title">Hello</h1>
jsconst title = document.getElementById("title");
title.textContent = "Hello Surya";

The page now displays: Hello Surya

textContent vs innerHTML

textContent

Treats the assigned value as plain text. Assigning "<strong>Hello</strong>" literally shows the tags on screen instead of rendering bold text.

innerHTML

Parses and inserts actual HTML — the same string would render "Hello" in bold, and can insert multiple elements at once.

jselement.innerHTML = `
    <h2>Welcome</h2>
    <p>This is a paragraph.</p>
`;
Security note: be careful when inserting user-controlled data with innerHTML — unsanitized HTML can introduce XSS vulnerabilities. For plain text, textContent is generally the safer choice.

07Styling with JavaScript

JavaScript can modify CSS directly through an element's style property.

jsconst title = document.querySelector("#title");

title.style.color = "red";
title.style.fontSize = "40px";
title.style.backgroundColor = "black";

CSS property naming in JavaScript

CSS uses kebab-case; JavaScript expects camelCase for the same properties:

CSS

background-color
font-size
margin-top

JavaScript

backgroundColor
fontSize
marginTop

Changing classes instead

Rather than setting individual styles repeatedly, it's usually cleaner to toggle a CSS class.

jsconst box = document.querySelector("#box");
box.classList.add("active");

classList methods

Method What it does
add() Adds a class
remove() Removes a class
toggle() Adds it if missing, removes it if present
contains() Checks whether the class exists

08Working with attributes

HTML elements carry attributes, such as src and alt in <img src="image.jpg" alt="Profile">. JavaScript can read and modify them directly.

jsconst image = document.querySelector("img");

// Read
console.log(image.getAttribute("src"));

// Write
image.setAttribute("src", "new-image.jpg");

// Remove
image.removeAttribute("alt");

09Creating and removing elements

JavaScript can build brand new elements with document.createElement():

jsconst paragraph = document.createElement("p");
paragraph.textContent = "This paragraph was created using JavaScript.";

At this point the element exists only in memory — it isn't visible yet. To place it on the page, use append() or appendChild():

jsconst container = document.querySelector(".container");
container.append(paragraph);
// or
container.appendChild(paragraph);

append() vs appendChild()

append()

Can insert multiple nodes and plain strings at once — e.g. container.append("Hello", paragraph). Usually more convenient in modern code.

appendChild()

Accepts a single node only, but is supported in older environments.

Removing elements

jsconst paragraph = document.querySelector("p");
paragraph.remove();

10DOM events

Events are one of the most important parts of DOM work. An event fires whenever something happens on the page — a click, a keystroke, a form submission, mouse movement, and so on.

addEventListener()

The recommended way to listen for any event:

html<button id="btn">Click Me</button>
jsconst button = document.querySelector("#btn");

button.addEventListener("click", function() {
    console.log("Button clicked!");
});

Common events

Event Fires when
click An element is clicked
mouseover The pointer enters an element
mouseout The pointer leaves an element
input A text field's value changes as you type
change A form control's value changes (e.g. select)
submit A form is submitted

The event object

Every handler receives an event object describing what happened, including event.target (the element that triggered it) and event.type.

jsbutton.addEventListener("click", function(event) {
    console.log(event.target);
});

Keyboard events

jsdocument.addEventListener("keydown", function(event) {

    if (event.key === "Enter") {
        console.log("Enter pressed");
    }

});

Form handling

html<form id="loginForm">
    <input id="username" type="text">
    <button type="submit">Login</button>
</form>
jsconst form = document.querySelector("#loginForm");

form.addEventListener("submit", function(event) {

    event.preventDefault();

    const username = document.querySelector("#username").value;
    console.log(username);

});

preventDefault() stops the browser's default form submission so JavaScript can validate or process the data first.

11DOM traversal

Traversal means moving between related elements in the DOM tree using properties like:

parentElement children firstElementChild lastElementChild nextElementSibling previousElementSibling 
jsconst item = document.querySelector(".item");
console.log(item.parentElement); // gets the parent

Given three sibling paragraphs, you can step from one to the next or previous:

html<p id="one">One</p>
<p id="two">Two</p>
<p id="three">Three</p>
jsconst first = document.querySelector("#one");
console.log(first.nextElementSibling); // selects "Two"

const third = document.querySelector("#three");
console.log(third.previousElementSibling); // selects "Two"

12Event bubbling and delegation

When you click a nested element, the event fires on that element first, then bubbles upward through each ancestor:

button ↑ div ↑ body ↑ html ↑ document
jsconst parent = document.querySelector("#parent");
const child = document.querySelector("#child");

parent.addEventListener("click", function() {
    console.log("Parent clicked");
});

child.addEventListener("click", function() {
    console.log("Button clicked");
});

// Clicking the button logs:
// Button clicked
// Parent clicked

Event delegation

Delegation uses bubbling to handle many elements with a single listener on their shared parent — especially useful for elements created dynamically.

jsconst list = document.querySelector("#list");

list.addEventListener("click", function(event) {

    if (event.target.matches("li")) {
        console.log("List item clicked");
    }

});

13DOMContentLoaded

A script can run before the HTML elements it needs actually exist. Waiting for DOMContentLoaded guarantees the document is fully parsed first — handy when a script sits in <head>.

jsdocument.addEventListener("DOMContentLoaded", function() {
    console.log("DOM loaded");
});

14Practical examples

Dynamic task list

html<input id="taskInput" type="text">
<button id="addBtn">Add Task</button>
<ul id="taskList"></ul>
jsconst input = document.querySelector("#taskInput");
const button = document.querySelector("#addBtn");
const list = document.querySelector("#taskList");

button.addEventListener("click", function() {

    const task = document.createElement("li");
    task.textContent = input.value;
    list.append(task);
    input.value = "";

});

This one pattern — select, create, append — is the foundation of todo apps, shopping carts, comment sections, dynamic menus, and dashboards.

Dark mode toggle

Let CSS own the design and JavaScript own the behavior:

css.dark {
    background-color: #111;
    color: white;
}
jsconst button = document.querySelector("#themeBtn");

button.addEventListener("click", function() {
    document.body.classList.toggle("dark");
});

Counter

jslet count = 0;

const display = document.querySelector("#count");
const increase = document.querySelector("#increase");
const decrease = document.querySelector("#decrease");

increase.addEventListener("click", function() {
    count++;
    display.textContent = count;
});

decrease.addEventListener("click", function() {
    count--;
    display.textContent = count;
});

Here JavaScript stores state in count, listens for clicks, updates the value, then reflects the change on screen with textContent.

Show / hide password

jsconst password = document.querySelector("#password");
const toggle = document.querySelector("#toggle");

toggle.addEventListener("click", function() {

    if (password.type === "password") {
        password.type = "text";
        toggle.textContent = "Hide Password";
    } else {
        password.type = "password";
        toggle.textContent = "Show Password";
    }

});

This shows how JavaScript can manipulate both attributes (type) and text content in the same handler.

15DOM vs BOM

A common interview question — and the distinction is straightforward:

DOM — Document Object Model

Represents the webpage itself: document.querySelector(), document.createElement(), document.getElementById()

BOM — Browser Object Model

Represents the browser around the page: window, location, history, navigator, screen

jsconsole.log(window.innerWidth); // viewport width, via the BOM

17Common mistakes & best practices

Mistake: selecting something that doesn't exist

jsconst button = document.querySelector("#wrongId");

// button is null here — calling .addEventListener on it throws an error
button.addEventListener("click", function() {
    console.log("Clicked");
});

Mistake: forgetting . or #

jsdocument.querySelector("box");   // looks for a <box> tag
document.querySelector(".box");  // looks for class="box"
document.querySelector("#box");  // looks for id="box"

Mistake: running JavaScript before the DOM exists

If a script runs before the elements it needs exist, selection silently fails. Fix it by placing the script tag right before </body>, or wrapping the code in DOMContentLoaded.

Best practices

  1. Prefer querySelector() / querySelectorAll() for their consistent CSS-selector syntax.
  2. Use classList to toggle CSS states instead of hand-editing className.
  3. Prefer textContent over innerHTML when you only need plain text.
  4. Use addEventListener() rather than inline onclick="..." attributes.
  5. Avoid unnecessary DOM operations — updates can be relatively expensive, so batch changes where practical.

18How the DOM works in a real application

Picture a shopping cart. The user clicks Add to Cart, and a chain of DOM-driven steps follows:

User clicks button ↓ Event listener executes ↓ Product information is read ↓ Cart state is updated ↓ DOM is updated ↓ Cart count changes ↓ Total price changes

That same select → listen → update loop powers most interactive websites you use every day.

21Conclusion

The DOM is one of the most important concepts in JavaScript because it's the connection between your code and the actual webpage a user sees.

The core pattern to remember is:

Select → Modify → Listen → Create → Update
jsconst button = document.querySelector("#button");

button.addEventListener("click", function() {

    const heading = document.querySelector("h1");

    heading.textContent = "Hello JavaScript!";
    heading.classList.toggle("active");

});

That small snippet is the whole idea of DOM programming in miniature: select an element, listen for an event, and dynamically change the page. Once selection, events, forms, traversal, and delegation feel natural, you'll have a solid foundation for building interactive apps — and for moving on to frameworks like React.
